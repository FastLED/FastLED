Cold slow-path helper for showPixels().

Resolve the driver for this channel.

Handles dynamic ChannelManager::selectDriverForChannel() lookup AND the bus-key-miss diagnostics (#2455 / #2459). This is now the only driver-resolution path.

Marked FL_NO_INLINE to keep showPixels() compact – see #2773 item 2.1. Returns nullptr on a hard miss (caller should silently bail).

Marked noinline (via FL_NO_INLINE) so the compiler doesn't fold the cold body back into showPixels.
