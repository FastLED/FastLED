fl::net::ble::BleNotifyQueue Class Reference

Detailed Description

Bounded FIFO of outbound notification payloads, drained in MTU-sized chunks.

Exactly one payload is "in flight" at a time: chunkData() / chunkSize() always describe the front payload at the current offset, and the front is popped only once advance() has consumed all of it.
