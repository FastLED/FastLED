wave3.h File Reference

Detailed Description

Out-of-line declarations for wave3 transposition internals.

Split from the former detail/wave3.hpp force-inline header. Callers now include this .h and link against detail/wave3.cpp.hpp. The transposes are still in IRAM and are still FL_OPTIMIZE_FUNCTION — they are just no longer force-inlined into every translation unit that references them. The unity build compiles the .cpp.hpp once and every caller resolves via normal link.
