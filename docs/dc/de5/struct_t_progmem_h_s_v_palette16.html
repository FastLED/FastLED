TProgmemHSVPalette16 Struct Reference

Detailed Description

CHSVPalette16 entries stored in PROGMEM memory.

A distinct struct rather than another fl::u32[16] alias. When this was an array typedef it was the same type as TProgmemRGBPalette16 – the names documented an intent the compiler could not enforce – so an RGB progmem palette bound silently to every CHSV palette constructor and loadProgmemPalette(CHSV*, ...) copied red/green/blue straight into hue/sat/val. Reported as FastLED#807 in 2019.

The implicit conversion keeps every legitimate use working unchanged: brace initialisation, pal[i] indexing, and passing one where a const fl::u32 * is expected. Only the unsafe direction is now rejected, because a bare fl::u32[16] will no longer convert to this type.
