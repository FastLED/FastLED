Encode pixels in HD108 format (zero allocation)

Parameters
outOutput buffer to write encoded bytes
Note
Protocol: 16-bit RGB with gamma correction and brightness control
Parameters
managedTrue when the source is the colour-managed one, i.e. loadAndScaleRGB16 yields a device drive rather than a widened 8-bit pixel. Then the fixed 2.8 gamma is skipped: it would be a second shaping stage after the device solve (#4326).
