Detailed Description

fl::net::wifi — platform-neutral WiFi connection API (FastLED#3576 Phase 6).

FastLED previously had no reusable connection manager: the only credential-taking API was OTA-scoped (fl::net::OTA::beginWiFi) and examples hand-rolled esp_wifi_* calls. This header is the fl-level surface for bringing a network interface up so the rest of fl::net (fetch, HTTP server, remote RPC) has something to run on.

All calls are asynchronous and non-blocking: connectSta() starts a join and returns; poll status() / isConnected(). On platforms without WiFi (host builds, WiFi-less MCUs like ESP32-H2) every call is a no-op stub that reports Status::UNSUPPORTED.

Bluetooth connections live in the sibling fl::net::ble API (GATT transport: createTransport / queryStatus).
