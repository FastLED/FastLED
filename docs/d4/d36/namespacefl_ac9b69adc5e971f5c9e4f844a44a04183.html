ChipsetTiming fl::uartWireTiming ( const ChipsetTimingConfig & timing,
u32 max_baud_rate )

The wire timing the UART encoder actually produces for a chipset.

The encoder quantises T0H/T1H onto a grid of period / pulses_per_bit, so what appears on the wire is not the chipset's nominal timing. A receiver decoding a UART-encoded frame has to classify against the quantised values, not the datasheet ones – otherwise it is matching a waveform nobody sent.

Derived through the same fitUartWave() rules that built the LUT, so the decode windows cannot drift from the encoding.

Parameters
timingChipset timing configuration
max_baud_rateBackend baud ceiling (selects the frame geometry)
Returns
Quantised wire timing, or a zeroed ChipsetTiming if infeasible
