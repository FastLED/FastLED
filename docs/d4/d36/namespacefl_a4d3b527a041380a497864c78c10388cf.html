HandleResult fl::canMatch ( const DriverCapabilities & caps,
fl::span< const PinGroup > groups,
const ChannelRequest & request )

Test a request (single-pin OR multi-pin ganged) against a driver's published capability data.

Parameters
capsDriver-wide descriptor (protocol gates, freq ranges, clockless timing model, flags).
groupsThe driver's per-resource group list.
requestChannel request — data_pins bitset + clock_pin + chipset timing windows + optional frequency override. A single-pin request has exactly one bit set in data_pins.
Returns
HandleResult::Yes if any group accepts the request; otherwise the strongest rejection reason observed across all groups.
