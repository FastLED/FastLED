Total wire bytes of a complete UCS7604 frame.

Preamble + padding + pixel data, the length encodeUCS7604 writes. Callers that must size a capture or predict whether a frame fits need this without encoding it first (FastLED#4371); encodeUCS7604 computes its own padding from here so the two cannot drift.
