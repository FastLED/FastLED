Detailed Description

template<typename T, typename = void>
struct fl::WideLoadBinder< T, typename >

Binds the wide thunk only when T declares loadAndScaleRGB16.

A plain PixelController does not, so nothing is emitted for it and the pointer stays null; PixelIterator::loadAndScaleRGB16 then widens the 8-bit load in one place instead of once per colour order.
