Detailed Description

Bodies for the format helpers declared in fl/fs/read.h.

Out-of-line on purpose. These forward to the corresponding FileSystem members, and every one of them ends in a file read, so the call costs nothing measurable against the I/O it wraps. Keeping the header to declarations means adding a format does not recompile every consumer of fl/fs/read.h.
