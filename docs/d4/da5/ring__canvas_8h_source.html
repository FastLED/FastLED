1// ring_canvas.h - ring geometry and additive drawing on a float ring.
2//
3// Positions are in turns: 0 is the first LED, 1 wraps back to it. Widths
4// are also in turns, so a lobe of width 0.05 covers 5% of the ring no
5// matter how many LEDs there are.
6//
7// Everything accumulates in float and is quantised to CRGB exactly once, in
8// MoodPainter. Scaling 8-bit values repeatedly is what produced the stair
9// steps in the old overlay: a dim pixel at 3 -> 2 -> 1 -> 0 is a visible
10// staircase, and a weight quantised to 1/255 steps between frames.
