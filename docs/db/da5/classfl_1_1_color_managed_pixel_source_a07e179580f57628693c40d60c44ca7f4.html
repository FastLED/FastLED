The colour-managed path.

Reads the raw pixel rather than loadAndScale0/1/2, deliberately. Those fold in mColorAdjustment, whose premixed carries brightness – and the pipeline carries brightness too, as C4's flux scalar, so going through them would apply it twice. Legacy correction and temperature are not a concern here: binding a profile clears them, which is what the LegacyClearedByProfile warning is for.
