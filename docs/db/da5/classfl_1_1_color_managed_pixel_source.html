fl::ColorManagedPixelSource Class Reference

Detailed Description

Runs processPixelQ16 over a PixelController's pixels as they are read.

RGB, RGBW and RGBWW use the physical profile matching their topology. Without a wide profile the white-channel methods retain the wrapped controller's legacy conversion and wire bytes.
