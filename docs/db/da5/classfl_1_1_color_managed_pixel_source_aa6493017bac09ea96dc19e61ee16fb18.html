The same pixel, quantized once to 16 bits instead of to 8 (P8, #4042).

B3 asks for a single final quantization. The 8-bit entry point above is that, for an 8-bit wire. A 16-bit encoder fed from it gets the drive narrowed to 256 levels and then widened again, which is a quantization the wire never asked for – measured on UCS7604-16 in #4326 as 252 of 65536 reachable levels.
