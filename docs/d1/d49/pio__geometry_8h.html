pio_geometry.h File Reference

Detailed Description

Sampler geometry of the RP PIO RX capture.

These numbers are the contract between the capture device and anything that has to predict whether a frame will fit in it, and they bound a capture in two independent ways (FastLED#4371):

  • kRpPioRxEdgeCapacity is a pool of signal phases, two per bit.
  • the DMA word count derived from it is a fixed quantity of wall clock, because each word holds kRpPioRxSamplesPerDmaWord pin samples taken at kRpPioRxClockHz.

They live here, portable and free of the RP build guard, so the device, the bound in fl/channels/validation.h and the host tests all read the same definitions instead of copies that can drift apart.
