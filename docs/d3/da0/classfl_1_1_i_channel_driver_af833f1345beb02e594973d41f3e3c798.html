virtual HandleResult fl::IChannelDriver::canMatch ( const ChannelRequest & request) const
inlinevirtual

Predicate: can this driver match a (single- or multi-pin) request?

Note
Base default delegates to free fl::canMatch on the published capability data. Drivers should NOT override unless they have dynamic constraints unrepresentable in static data.
A single-pin request has exactly one bit set in request.data_pins (use ChannelRequest::singlePin() factory).
