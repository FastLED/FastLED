fl::StaticProfileChannel< Profile > Class Template Reference

Detailed Description

template<const EmitterProfile & Profile>
class fl::StaticProfileChannel< Profile >

A compile-time profile channel.

Its identity is carried solely in the vtable override; it adds no per-instance profile pointer or owned storage.
