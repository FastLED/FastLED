3// From a channel's colour-profile binding to a running pipeline (P6, #4040).
4//
5// `ColorProfileBinding` has carried a source profile, an emitter profile and
6// a gamut policy for a while, and nothing read them: the binding's
7// acceptance was tracked, but no pixel ever went through it. This is the
8// adapter that turns one into a `StreamingPipelineQ16`.
9//
10// It lives here rather than in fl/gfx because the dependency runs that way
11// round -- channels already include gfx headers, and gfx must not learn
12// about channels.
