3// Per-chip 5-bit field semantics for the colour-managed HD path (P8, B1,
4// #4042).
5//
6// APA102-class parts drive their 5-bit field as a secondary slow PWM stage,
7// so a joint code/field solve may use it for low-light resolution, bounded
8// below by a flicker floor. SK9822's field is a current gain whose effect on
9// chromaticity is not characterised, so it is held fixed. A chip whose
10// semantics are not known gets the SK9822-conservative treatment. A bound
11// profile's `five_bit_semantics`, when it says anything, overrides the chip's
12// default.
