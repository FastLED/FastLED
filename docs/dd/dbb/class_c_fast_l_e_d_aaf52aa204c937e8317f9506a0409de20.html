void CFastLED::setRgbwColorimetricProfile ( const fl::DiodeProfile * profile)
inline

Install a legacy fallback RGBW diode chromaticity profile for scalar colorimetric calls.

The pointer is stored; caller must keep the DiodeProfile alive for as long as a colorimetric mode may use it. No-op when FASTLED_RGBW_COLORIMETRIC is undefined.
