FL_KEEP_ALIVE void CFastLED::show ( fl::u8 scale)

Update all our controllers with the current led colors, using the passed in brightness.

Parameters
scalethe brightness value to use in place of the stored value
Warning
This function is not interrupt-safe and must not be called from an interrupt service routine (ISR). On ESP32, doing so can deadlock or trigger an interrupt-watchdog panic. Have the ISR set a flag, then call show() from loop() or a normal task after leaving the interrupt context.
